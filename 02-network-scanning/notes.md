**Отчёт по главе 1 (часть 2)**

Сканирование сети (Network Scanning)
По материалам книги «Этичный хакинг» Дэниела Грэма (2022)

*Цель работы*

Освоить базовые приёмы разведки (reconnaissance) в локальной сети: обнаружение активных хостов, выявление уязвимой учебной машины Metasploitable и получение доступа к ней через заранее известную уязвимость (бэкдор), с подтверждением доступа и проверкой возможности выполнения команд.

*Используемые инструменты*

•	netdiscover — обнаружение активных хостов в локальной сети

•	Metasploitable — заведомо уязвимая учебная виртуальная машина

•	Kali Linux — атакующая машина 

•	netcat (nc) — установление сетевого соединения с бэкдором

•	Стандартные shell-команды (whoami, reboot) — проверка полученного доступа

*Ход работы*

1. Обнаружение хостов в сети.

С помощью утилиты netdiscover выполнено сканирование локальной сети лаборатории для обнаружения активных устройств. В результате в сети была обнаружена виртуальная машина Metasploitable — специально уязвимый дистрибутив, предназначенный для учебной эксплуатации.

2. Получение доступа через бэкдор.

На машине Metasploitable присутствует заранее известная уязвимость — открытый бэкдор на одном из сетевых портов. Соединение с ним было установлено с помощью утилиты netcat:
nc -v <IP_адрес_цели> <порт>
Флаг -v (verbose) использовался для подробного вывода информации о процессе соединения.

3. Подтверждение доступа.

После успешного подключения через бэкдор была получена командная оболочка на целевой машине. Для проверки уровня полученного доступа выполнена команда:
whoami
Команда подтвердила, что соединение действительно предоставляет доступ к выполнению команд на целевой системе.

4. Проверка возможности управления системой.

В качестве финальной демонстрации полученного контроля над системой была выполнена команда перезагрузки:
reboot
Успешное выполнение команды продемонстрировало полный контроль над целевой машиной через эксплуатацию бэкдора.

*Результат*

•	Обнаружен уязвимый хост Metasploitable в локальной сети с помощью netdiscover

•	Установлен доступ к целевой машине через известный бэкдор с помощью netcat

•	Подтверждена возможность выполнения произвольных команд (whoami, reboot)

*Вывод*

Практическая работа продемонстрировала базовый сценарий атаки: разведка сети → обнаружение уязвимой цели → эксплуатация известной уязвимости → получение и подтверждение доступа. Все действия выполнены в изолированной учебной лаборатории на заведомо уязвимой машине Metasploitable, предназначенной именно для подобных учебных задач.
